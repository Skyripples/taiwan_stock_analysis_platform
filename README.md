# 台股投資分析平台 V3.9

## 功能

- 平台首頁、共用 Header、Sidebar、Page Framework 與 Widget 系統
- 台股事件簿：除權息、股東會、法說會等事件月曆
- 市場總覽：台股市場指標、國際市場、三大法人、外資台指期與 Market Score
- 籌碼分析 Beta：
  - 三大法人、外資台指期與融資融券最新資料
  - 最近 250 個交易日籌碼歷史與 20／60 日趨勢
  - 法人連續買賣、5／20 日累計、期貨部位與融資融券變化
  - 法人、期貨與融資籌碼狀態及 20 日歷史相對位置
- 個股分析 Beta：
  - 支援上市／上櫃股票代號及公司名稱搜尋
  - 顯示行情、PE、PB、殖利率、營收、EPS、ROE、獲利率與財務風險指標
  - 顯示個股三大法人、融資融券及近 5／20 日籌碼統計
  - 提供公開規則式基本面健檢，ETF 自動排除不適用的公司財報分析
  - 使用靜態資料快取架構，可透過建置腳本擴充任意上市／上櫃標的
- V3.7 個股估值與健檢強化：
  - 一般公司提供近 3／5 年 PE、PB、殖利率歷史區間與百分位
  - 成長股、地雷股、便宜股、績優股四類公開規則式健檢，不足資料明確標示 unavailable
  - 個股籌碼擴充為 60 個交易日，支援 20／60 日法人及融資融券趨勢
  - 顯示公司與同產業 PE、PB、殖利率、ROE、EPS、營收成長中位數及百分位比較
- V3.8 多期財報與財務趨勢：
  - 一般公司保存最近 12 季官方合併財報，ETF 自動排除
  - 顯示 EPS、營收、獲利率、ROE、負債比、OCF 與 FCF 的近 8／12 季趨勢
  - 正確將累計現金流還原為單季，計算 TTM EPS、OCF、FCF 與 QoQ／YoY
  - 四大健檢納入成長、衰退、獲利穩定、現金流及財務結構趨勢
- V3.9 同業比較強化：
  - 依相同產業與可比較財報期間，顯示公司數值、同業中位數、百分位與排名
  - 同業指標分為估值、成長、獲利與財務安全，並提供可解釋的相對狀態
  - 提供 ROE、EPS、營收年增率、PE、PB 的同業前 10 名排行
  - 排除無效數值、負 PE、財報期間不一致公司；ETF 不套用公司同業排名
- 隔日行情預測 Beta：
  - 使用 15 個正式市場特徵的 Logistic Regression Baseline Model
  - 依時間序列進行 Walk-forward Validation，避免未來資料洩漏
  - 使用 Platt Calibration 校準上漲與下跌機率
  - 顯示模型指標、Feature 清單、預測方向、機率與信心度
- V3.4 Feature Engineering 與模型定版：
  - 全球市場、VIX、KOSPI 與半導體產業候選因子分析
  - Feature Correlation、Ablation、Robustness 與 Pruning Validation
  - Temporal Leakage Audit 與台股 Trading Calendar
  - 正式模型移除冗餘的平盤家數，定版為 15 Features
- 每日市場資料、歷史資料、監督式訓練資料與預測驗證紀錄自動更新
- 深色／淺色模式與桌面、平板、手機響應式版面

## 資料來源

- 臺灣證券交易所（TWSE）：加權指數、上市個股行情與估值、公司財報、成交金額、漲跌家數、三大法人、融資融券與交易日資訊
- 證券櫃檯買賣中心（TPEx）：櫃買指數、上櫃個股行情與估值、公司財報、成交金額、三大法人與融資融券
- 臺灣期貨交易所（TAIFEX）：外資臺股期貨未平倉與臺股期貨夜盤
- Yahoo Finance：TSM ADR、SOX、S&P 500、NASDAQ、VIX、KOSPI，以及研究用國際與半導體候選資料
- Federal Reserve Economic Data（FRED）：研究用美國公債殖利率候選資料
- 公開資訊觀測站（MOPS）：台股事件簿公開資訊，以及上市櫃公司合併資產負債表、綜合損益表與現金流量表
